How to use

1. Paste one song, set the title + key.
2. For Ukrainian/Russian sheets that use H for B, tick Slavic notation.
3. Check the preview: each chord should sit over the right syllable. Source sheets that are well aligned convert cleanly; if a chord is one syllable off, nudge it in the left box.
4. Click Copy as songs.js block and paste it into the SONGS array in songs.js.
5. For a bilingual song, tick Add a 2nd language, fill in both sheets (each with its own key and Slavic-notation setting), then Copy as songs.js block — it outputs the full versions object ready to paste.
